## 1. 产品概述

一个极简而富有文学气质的个人博客，以"墨与纸"为设计灵感，融合东方留白美学与现代排版设计，为读者提供沉浸式的阅读体验。

- 面向热爱写作与阅读的知识工作者，打造安静、专注的内容空间
- 以内容为核心，用极致的排版和微妙的动效传递文字的力量

## 2. 核心功能

### 2.1 功能模块

1. **首页**：个人品牌展示区、精选文章、最新文章列表、分类标签
2. **文章详情页**：沉浸式阅读体验、目录导航、文章元信息
3. **归档页**：按时间线浏览所有文章、分类筛选、标签云

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | Hero 区域 | 个人签名、简短介绍、背景氛围动效 |
| 首页 | 精选文章 | 大卡片展示 1-2 篇推荐文章，配图+摘要 |
| 首页 | 最新文章 | 列表式展示近期文章，含日期和分类标签 |
| 首页 | 分类标签 | 侧边栏或底部展示文章分类和热门标签 |
| 文章详情页 | 文章头部 | 标题、日期、分类、阅读时长、封面图 |
| 文章详情页 | 目录导航 | 侧边悬浮目录，滚动高亮当前章节 |
| 文章详情页 | 正文区域 | 优雅排版、代码高亮、引用块、图片展示 |
| 文章详情页 | 文章底部 | 标签、上下篇文章导航 |
| 归档页 | 时间线 | 按年月分组的文章列表 |
| 归档页 | 筛选器 | 分类筛选、标签云点击筛选 |

## 3. 核心流程

用户访问首页 → 浏览精选/最新文章 → 点击进入文章详情页阅读 → 通过目录导航跳转章节 → 阅读完毕浏览上下篇 → 返回首页或进入归档页探索更多内容

## 4. 用户界面设计

### 4.1 设计风格

- **美学方向**：墨纸书卷风 — 东方留白 + 现代编辑排版，追求"少即是多"的克制美学
- **主色调**：墨黑 `#1a1a2e` 为底，纸白 `#f5f0eb` 为面，朱砂红 `#c0392b` 为点缀
- **辅助色**：淡金 `#d4a574`、灰墨 `#4a4a5a`、暖白 `#faf8f5`
- **字体**：标题使用 Noto Serif SC（宋体韵味），正文使用 Noto Sans SC（清晰易读）
- **布局**：大量留白，单栏阅读为主，最大宽度 720px，行高 1.8
- **动效**：页面切换淡入、文字逐行显现、滚动视差微动、悬浮墨迹扩散效果
- **图标**：线性极简风格，线条 1.5px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 首页 | Hero 区域 | 全屏高度、居中签名文字、背景水墨晕染动效、向下滚动指示器 |
| 首页 | 精选文章 | 大尺寸卡片、左侧封面图右侧文字、悬浮时微上浮+阴影加深 |
| 首页 | 最新文章 | 简洁列表、日期+标题+分类标签、交替淡入动效 |
| 文章详情页 | 文章头部 | 大标题居中、日期与分类信息、封面图全宽展示 |
| 文章详情页 | 目录导航 | 右侧悬浮、当前章节高亮带朱砂红竖线 |
| 文章详情页 | 正文区域 | 宋体标题、无衬线正文、引用块左侧朱砂红竖线、代码块深色背景 |
| 归档页 | 时间线 | 左侧竖线+年份节点、右侧文章列表、朱砂红节点标记 |

### 4.3 响应式设计

- 桌面优先设计，最大内容宽度 1200px
- 平板（≤1024px）：隐藏侧边目录，调整卡片为单列
- 手机（≤640px）：全宽布局，字号微调，底部固定导航栏
